# Rally Beta

## Rollout Ladder

1. Founder alpha: Naman plus seeded accounts.
2. Friends alpha: 6-10 trusted testers.
3. Closed Beta 01: around 20 qualified singles.
4. Closed Beta 02: 40-60 users only if density and behavior are promising.
5. UIUC expansion after evidence.

## Metrics

- Profile completion.
- Compatible match density.
- Rally request rate.
- Request to accept.
- Accepted to scheduled.
- Scheduled to played.
- Played to Rally Again.
- Mutual Rally Again.
- Repeat/referral.
- Cancellation, no-show, report rate.

## Safety Baseline

- 18+ beta.
- UIUC email verification.
- Public campus sports facilities as default first Rally locations.
- Block/report/cancel must be obvious and functional.
- Manual moderation decisions at beta scale.
- Plain-language privacy notice and community guidelines before strangers are invited.
