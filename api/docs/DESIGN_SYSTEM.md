# Rally Design System

## Voice

Confident, playful, concise, campus-native. Avoid excessive sports puns.

## UI Principles

- Mobile-first.
- Trustworthy before flashy.
- Clear primary action: Send Rally.
- Safety actions must be visible and plain-language.
- Founder console should be dense and scannable, not decorative.

## Visual Tokens

- Primary: court green.
- Accent: tennis-ball yellow.
- Support: ink, clay, sky, white.
- Radius: 8px for cards and controls.
- Cards: only for repeated items, modals, and tool panels.
- Buttons: clear filled primary, quiet secondary, visible destructive.
